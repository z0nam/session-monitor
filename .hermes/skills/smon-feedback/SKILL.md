# smon 피드백 — 세션 상태 되먹임 (Hermes 전용)

smon은 이 맥에서 도는 모든 AI 에이전트 세션의 상태 보드다. 매일 아침 `smon report`를
재료로 쓴 리포트가 나가고, 주인은 하루를 지나며 "그건 끝났어 / 그건 일단락"을 알려준다.
이 스킬은 그 말을 받아 **smon 보드에 반영**한다. 리포트와 보드가 따로 놀지 않게, 주인이
한 말이 곧 상태가 되게 하는 되먹임 고리다.

**범위: 보드 상태 되먹임 전용(MVP).** 실제 후속 작업(메일 발송·회의 잡기·파일 수정·커밋
등)은 이 스킬로 하지 않는다. 주인이 그런 실행까지 시키면 "지금은 보드 상태 반영만 한다"고
한 줄로 답하고, 해당 항목 상태만 처리하거나 그대로 둔다.

## 언제 발동하나

주인이 Slack에서 프로젝트 진행을 알릴 때. 예:
- "IRB 보고 끝냈어", "소방 경제효과 종결", "모요 쿠폰 등록했음" → **완료(done)**
- "G20은 일단락, TF 회의 잡히면 다시", "llm-study 4단계는 나중에", "그건 답 기다리는 중" → **일단락/대기(dir)**
- 한 메시지에 여러 건이 섞여 있으면 각각 처리한다.

주의: 주인이 **새 작업을 지시**하는 것(예: "G20 회의 잡아줘")은 이 스킬 범위가 아니다 —
위 "범위" 규칙대로 응대한다.

## 흐름

1. **발화에서 (프로젝트, 의도)를 뽑는다.**
   - 완료 신호: 끝/완료/종결/머지됨/보냈어/제출함/올렸어 → `done`
   - 일단락·대기 신호: 일단락/다음은/대기/답 기다림/나중에/보류 → `dir`
   - 애매하면 의도를 지어내지 말고 주인에게 확인한다.

2. **프로젝트를 세션으로 특정한다 (추측 금지).**
   - `smon find <키워드>` 로 후보를 찾는다 (요약·프로젝트 경로·세션ID 전문검색).
   - **done/dir은 로컬·비종료 세션에만 먹는다** (sid를 로컬 `sessions`에서 `state!='ENDED'`로
     찾기 때문). `smon find`·`smon report`는 **다른 머신·종료된 세션까지** 섞어서 보여주므로,
     후보를 고르기 전에 `smon find` 출력의 **MACHINE 열이 이 머신(로컬)이고 STATE가
     ENDED가 아닌지** 확인한다.
     - 유일 후보라도 **다른 머신**(mbp·mac-mini·namun-ji·sunshine 등) 세션이면 적용하지
       말고 "그건 <머신> 세션이라 여기서 보드 상태를 못 바꾼다"고 보고한다.
     - 유일 후보라도 **이미 ENDED** 면 "이미 종료된 세션이라 되먹임이 불필요하다"고 보고한다.
   - 로컬·비종료 후보가 정확히 1개면 그 세션ID를 쓴다.
   - 여러 개면 요약·프로젝트 경로로 가장 맞는 것을 고른다. 그래도 **애매하면
     주인에게 되묻는다** — sid 앞자리와 한 줄 요약을 나란히 제시해 고르게 한다.
   - 못 찾으면 지어내지 말고 "그 프로젝트의 smon 세션을 못 찾았다"고 말한다.

3. **상태를 적용한다.**
   - 완료: `smon done <sid앞자리>`  → 보드에서 초록(진짜 완료, 확인 후 끌 수 있음)
   - 일단락: `smon dir <sid앞자리>` → 보드에서 파랑(일단락·다음 지침 대기)
   - 세션ID는 앞 8자리면 충분하다. 명령이 실패하면 출력을 그대로 전한다.

4. **한 줄로 결과를 보고한다.**
   - 반영한 항목(프로젝트명 · sid 앞자리 · done/dir)과 못 정한 항목을 묶어서.
   - 예: "✅ 3건 반영 — IRB(d623d577) done · 소방(bae33433) done · G20(2518ee53) dir.
     '모요'는 세션이 2개라 어느 거부터인지 알려줘."

## 규칙

- 읽기(`smon`, `smon find`, `smon tail`, `smon report`)는 자유.
  상태를 바꾸는 건 **`done`·`dir`만** 이 스킬에서 쓴다.
- `smon ack`(초록 확인하고 끄기)는 주인이 명시적으로 "확인했어 / 꺼 / 지워"라고 할 때만.
- 세션을 못 찾으면 상태를 만들지 않는다. 조용히 아무 세션이나 건드리지 말 것.
- **외부 행동 금지** — 이 스킬은 smon 보드 상태만 만진다. 그 외는 범위 밖.
- 여러 건은 한 번에 처리하고 한 덩어리로 보고한다. 과설명하지 말 것.
- smon 명령 전반은 심링크된 `smon` 스킬 참조.
